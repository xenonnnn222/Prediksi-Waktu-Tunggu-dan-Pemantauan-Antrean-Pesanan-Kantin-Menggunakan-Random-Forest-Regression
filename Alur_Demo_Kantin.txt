2. SOLUSI & DUA ALUR WORKFLOW (2 menit)
---------------------------------------
Ucapkan:
"Kami membangun prototipe web lokal (Python, Flask, SQLite, React, scikit-learn)
dengan dua alur workflow:

Pertama, Workflow Operasional: Pembeli pilih menu -> Sistem simpan pesanan dan
memotret kondisi antrean aktif saat itu (snapshot_json) -> Model Random Forest
menghitung Estimasi Awal -> Petugas mengubah status Menunggu -> Diproses -> Siap
-> Selesai -> Nomor tampil otomatis di papan publik saat Siap dan hilang saat
Selesai. Jika model tidak tersedia, pesanan tetap dicatat dengan aman.

Kedua, Workflow Data & Model ML di notebook Kaggle: 1.526 pesanan simulasi dari
30 menu asli -> validasi & pembersihan -> bentuk target Y (waktu_siap - waktu_pesan)
dan 5 fitur X saat pesanan masuk (menu, jumlah, antrean_di_depan, jam_pesan,
hari_pesan) -> pembagian kronologis 70% latih (1.068), 15% validasi (229), 15%
uji (229) dengan penyaringan batas periode anti data leakage -> One-Hot Encoding
menu dipelajari hanya dari data latih -> pilih min_samples_leaf (2 vs 5, terpilih 2
dengan MAE validasi 1,76 menit) -> latih ulang pada latih+validasi -> uji semua
metode pada data uji yang sama."


3. HASIL & MENONJOLKAN MODEL RANDOM FOREST (2,5 menit)
------------------------------------------------------
Tampilkan tabel hasil Kaggle pada 229 data uji simulasi:
- Linear Regression : MAE 5,01 menit | RMSE 8,20 menit
- Random Forest     : MAE 6,14 menit | RMSE 11,38 menit  (100 pohon, min_samples_leaf=2)
- Baseline Median   : MAE 10,17 menit | RMSE 17,61 menit

Ucapkan:
"Algoritma utama yang kami bangun adalah Random Forest Regression (100 pohon
keputusan dengan bootstrap sampling; parameter aktual di kode memakai default
scikit-learn max_features=1.0). Random Forest memangkas MAE hampir 40% dibanding
baseline Median.

Mengapa di skor total Linear Regression lebih rendah? Dari error analysis data uji:
- Pada 196 dari 229 pesanan uji yang antreannya masih dalam rentang latih
  (antrean <= 10), Random Forest sebenarnya LEBIH UNGGUL (MAE 2,54 vs 2,62 menit).
- Namun pada 33 pesanan uji terakhir terjadi lonjakan simulasi hingga 18 antrean
  (tunggu hingga 61,33 menit), padahal data latih maksimum hanya 10 antrean
  (29,08 menit). Karena pohon keputusan tidak dapat mengekstrapolasi di atas nilai
  target latih, prediksi Random Forest mentok di 24,52 menit, sedangkan Linear
  Regression terus naik linear. Ini membuktikan pentingnya cakupan data jam puncak
  saat pengumpulan data nyata nanti."
